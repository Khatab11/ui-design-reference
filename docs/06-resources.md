## حماية الحسابات — اقرا ده قبل ما تبعت

**الإرسال الجماعي السريع بيتسبّب في حظر الحسابات.** ده مش احتمال نظري. مع أرقام زي اللي إحنا مستهدفينها، بيحصل فعلًا.

**لو حسابك اتقفل في نص اليوم، هتخسر نتايجك كلها.**

### قواعد إلزامية

**وزّعوا الإرسال على أعضاء الفريق.** متخلّوش شخص واحد يبعت 22 رسالة.

**شخصنوا كل رسالة.** غيّروا الاسم على الأقل، وحبّذا سطر واحد يخص الشخص ده. نفس النص حرفيًا لعشرات الناس هو أوضح إشارة للحظر.

**باعدوا بين الرسايل.** مش الـ 22 في خمس دقايق.

**ابدأوا بالأقرب.** الناس اللي بتعرفكم فعلًا بترد أكتر وبتبلّغ أقل.

**استخدموا حساب مش أساسي لو ينفع.**

### لو الحساب اتقفل

1. بلّغ الفريق المسهّل فورًا
2. حوّل لقناة تانية — إيميل، لينكدإن
3. باقي أعضاء الفريق يوزّعوا نصيبك
4. متحاولش تفتح الحساب بنفس الطريقة

## قالب رسالة الوصول

**متنسخوش ده حرفيًا.** ده هيكل، عدّلوه لكل شخص.

```
[الاسم]، عامل إيه؟

إحنا بنبني مرجع عربي مفتوح المصدر للتصميم اسمه
«ما ليس على المصمّم جهله». لسه في أوله.

حابب أعرف رأيك بصراحة — الرابط:
[الرابط]

ولو تقدر تجاوب 5 أسئلة سريعة، ده بيفرق معانا جدًا:
[رابط الاستبيان]

شكرًا.
```

**قواعد الرسالة:**

- الرابطين بس. متضيفوش حاجات تانية.
- قصيرة. الرسالة الطويلة مبتتقريش.
- اطلبوا الرأي، مش المدح. «حابب أعرف رأيك بصراحة» بترجّع ردود أنفع من «شوف شغلنا».
- متبررش. الاعتذار عن كون المشروع ناقص بيخلّي الرد مجاملة.

## قالب المحتوى

كل قسم بيتكتب في ملف JSON بالبنية دي:

```json
{
  "id": "chapter-slug",
  "order": 5,
  "title": { "en": "...", "ar": "..." },
  "intro": { "en": "...", "ar": "..." },
  "sections": [
    {
      "id": "section-slug",
      "title": { "en": "...", "ar": "..." },
      "body":  { "en": "markdown", "ar": "markdown" },
      "asset": {
        "file": "name.png",
        "alt": { "en": "...", "ar": "..." },
        "ratio": "16:9",
        "brief": "وصف الصورة المطلوبة"
      },
      "callout": { "type": "tip", "en": "...", "ar": "..." }
    }
  ]
}
```

`asset` و `callout` اختياريين. أنواع الـ callout: `tip | warning | quote | note`.

**`note`** = إضافة من عندنا مش من المصدر الأصلي. استخدموه لأي حاجة تخص السياق العربي.

**لو الصورة لسه متعملتش**، سيبوا `asset` موجود والموقع هيعرض placeholder فيه الـ `brief`. ده بيخليكم تنشروا من غير ما تستنوا التصميم.

**التحقق قبل النشر:**

```bash
npx --yes ajv-cli@5 validate --spec=draft7 -s schema/chapter.schema.json -d "content/*.json"
```

## برومبتات جاهزة

### توليد قسم محتوى

```
اكتب قسم لمرجع تصميم عربي مفتوح المصدر.

الموضوع: [الموضوع]
الجمهور: مصمّمين عرب في أول 3 سنين

المطلوب:
- اشرح المبدأ واشرح ليه، مش إزاي بس
- مثال ملموس، ويفضّل مقارنة صح وغلط
- عربي وإنجليزي، كل واحد مكتوب لجمهوره مش مترجم حرفيًا
- المصطلحات اللاتينية تفضل لاتينية جوه النص العربي
- لو المبدأ مش بينطبق على العربي بنفس الشكل، قول ده في callout من نوع note

أخرج JSON بالبنية المرفقة بس، من غير أي شرح.
```

### مراجعة قسم

```
راجع قسم المحتوى ده لمرجع تصميم عربي.

اتأكد من:
1. الدقة الفنية — فيه أي حاجة غلط أو قديمة؟
2. العربي مكتوب أصلي ولا مترجم حرفي؟
3. بيشرح ليه ولا بيعرّف بس؟
4. فيه مثال ملموس؟
5. فيه ادعاء محتاج مصدر ومش موجود؟
6. أي مبدأ لاتيني اتطبّق على العربي من غير ما يتقال إنه مختلف؟

اطلع بقايمة مشاكل محدّدة. متعيدش الكتابة.
```

### توليد دياجرام SVG

```
اعمل SVG لدياجرام تعليمي.

المطلوب توضيحه: [الوصف]

القيود:
- viewBox 1600x900، خلفية شفافة
- فيكتور مسطّح، من غير جراديينت ولا ظلال إلا لو الدياجرام نفسه عن الظلال
- رماديات دافية + لون accent واحد للحاجة اللي بنشاور عليها
- الليبلات بخط Inter، خطوط التعليق 1px
- مقروء على الوضع الفاتح والغامق
- مقروء على عرض 400px

مهم: القيم لازم تكون دقيقة هندسيًا مش تقريبية.
```
